Qué es

Software web con login que detecta filtraciones de música no lanzada. Busca, por palabras clave, subidas no oficiales de los temas de un artista y las muestra en un panel — todo dentro de la plataforma, sin herramientas externas. Es white-label: la marca se personaliza por cliente.

01 Qué construimos ya funciona

  • Login + panel protegido; gestión de artistas y keywords.
  • Motor de escaneo (YouTube + Spotify): deduplica, controla cuota y filtra ruido (reacciones, type beats, lyric videos, lives, noticias) y falsos positivos (relevancia + canales oficiales).
  • Notificaciones en vivo (campanita), dashboard con KPIs, filtraciones agrupadas por mes, estados (nueva → revisada → takedown → resuelta).
  • White-label configurable desde Ajustes (marca, color, textos).
  • Probado con datos reales: detectó filtraciones reales en YouTube y en Spotify.

03 Qué tiene que hacer The Orchard (incluida la cuota)

YouTube (motor principal, gratis):

  • Crear una YouTube Data API Key en Google Cloud.
  • Cuota gratis = 10.000 unidades/día (~100 búsquedas). Para más → llenar el formulario oficial y gratis YouTube API Services - Audit and Quota Extension Form (lo aprueban para casos legítimos como Sony).
  • Pegar la key en Ajustes.

Spotify (complemento, requiere acceso):

  • Crear una app propia bajo la cuenta de la empresa.
  • Solicitar "Extended Quota Mode" (formulario oficial gratis). Como son socios de Spotify, lo consiguen fácil.
  • Pegar Client ID + Secret en Ajustes.

Operación diaria: cargar artistas + keywords (títulos de temas NO lanzados), configurar el canal oficial de cada artista, y revisar/gestionar filtraciones.

04 Estado y qué falta para "enterprise"

  • Producto funcional y probado; código en GitHub.
  • Falta el deploy a la nube (Vercel) → URL pública.
  • Para venta formal a Sony: auth real + roles, DB de producción con backups, monitoreo (Sentry/uptime/audit log), seguridad (cuestionario de proveedor + DPA), y legal (entidad + contrato + SLA, con abogado).

05 El camino

Deploy → Demo → Piloto pagado → (si dicen sí) → Endurecer enterprise

Ningún SaaS es "sin errores para siempre". Lo enterprise es confiabilidad (monitoreo + backups + soporte + SLA), no cero errores — y se construye a medida que crece la relación con el cliente.
